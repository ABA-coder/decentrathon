# Запуск ProcureAI KZ

FastAPI обслуживает интерфейс и API с одного адреса. Отдельный frontend-хостинг не нужен.

## Локально

```sh
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Открыть http://localhost:8000. Проверка сервера: `/health`. Документация API: `/docs`.
`.env.example` описывает настройки; значения нужно задать в окружении процесса.
Приложение не загружает `.env` автоматически.

## Render

1. Подключить GitHub-репозиторий к Render и выбрать ветку с исправлениями.
2. Создать Blueprint по `render.yaml` либо Web Service с Python 3.12.
3. Build: `pip install -r requirements.txt`.
4. Start: `uvicorn main:app --host 0.0.0.0 --port $PORT --workers 1`.
5. Добавить `OPENAI_API_KEY` через настройки Environment сервиса. Не хранить ключ в Git.
6. Дождаться успешного деплоя и открыть выданный Render адрес.

Настройки:

| Переменная | Назначение |
|---|---|
| `OPENAI_API_KEY` | Серверный ключ для GPT; без него работают ML и правила, GPT явно отмечен как недоступный |
| `OPENAI_MODEL` | Модель OpenAI, по умолчанию `gpt-4o` |
| `ADMIN_API_KEY` | Доступ к переобучению; при отсутствии endpoint отключён |
| `MODEL_PATH` | Путь к локальному файлу модели; в Render `/tmp/procureai-kz/model.pkl` |
| `CORS_ORIGINS` | Необязательные разрешённые origins через запятую, если интерфейс размещён отдельно |

`render.yaml` выбирает бесплатный план. У него возможны остановка при простое и холодный старт.
Временный файл модели не является постоянным хранилищем: после пересоздания сервиса
приложение обучит базовую модель заново. Для сохранения переобученной модели нужен постоянный диск.

## Проверки

```sh
pip install -r requirements-dev.txt
python -m pytest tests -q
```

Тесты используют отдельную временную модель, не вызывают реальный OpenAI и не запускают
успешное административное переобучение. OpenAI-подключение окончательно проверяется после
настройки настоящего ключа на хостинге.

## Данные и доступ

Реестр содержит 250 синтетических тендеров. ML-расчёты выполняются на сервере настоящей
моделью Isolation Forest. Интеграции с госреестром нет. При недоступности сервера интерфейс
показывает ошибку, а не случайные результаты. Ответ по правилам явно отличается от GPT.

Переобучение требует заголовок `X-Admin-Key`; ключ вводится только для этой операции
и не сохраняется в браузере. Остальные API открыты, включая GPT-анализ: доступ посетителей
к GPT расходует лимит владельца OpenAI-ключа. Для публичной эксплуатации следует настроить
аутентификацию/квоты и ограничения расходов проекта OpenAI.
